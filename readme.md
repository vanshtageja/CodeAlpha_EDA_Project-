# Exploratory Data Analysis on Superstore Sales Dataset

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Superstore Sales Dataset to uncover sales trends, profitability patterns, customer behavior, and regional performance.

## Objectives
- Understand dataset structure
- Perform data cleaning
- Analyze sales and profit trends
- Identify top-performing categories and regions
- Generate actionable business insights

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Technology category generated the highest sales and profit.
- West region recorded the highest sales.
- California was the most profitable state.
- Consumer segment generated the highest revenue.
